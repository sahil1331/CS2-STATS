Privacy Policy for CS2 STATS

This extension does not collect, store, or transmit any personal user data. It only requires access to Steam community and store pages to inject navigation buttons. No data is shared with third parties.

Please note that CS2 STATS is an independent tool and is not affiliated with Valve, Steam, or any of the supported tracking websites; all credit for the statistical data and match analysis belongs entirely to those respective third-party platforms.
